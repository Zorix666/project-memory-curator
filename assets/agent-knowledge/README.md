# 项目知识库

<!-- project-memory-curator:auto-save=off -->

本目录保存会影响未来工程任务的长期上下文。Markdown 是唯一持久化载体；任何具备文件读写能力的开发 Agent 都可读取和维护。

## 使用原则

- 只保存已确认、可复用、与工程工作长期相关的信息。
- 不保存完整聊天、原始长日志、一次性细节或未经确认的猜测。
- 不保存密钥、Token、密码、凭据、个人隐私、客户数据、私有 URL、邮箱或用户名。
- `todo-memory.md` 仅包含待确认候选，不得当作事实使用。
- 项目的 `AGENTS.md`、`CLAUDE.md`、`.cursor/rules`、`.github/copilot-instructions.md` 等既有规范优先；冲突时停止应用本知识库中的冲突项。

## 索引与分类

| 文件 | 内容 | 不应包含 |
| --- | --- | --- |
| `project.md` | 技术栈、目录、模块、架构边界 | 临时实现细节 |
| `preferences.md` | 用户确认的长期偏好、禁忌、协作习惯 | 推测出的偏好 |
| `runbook.md` | 已验证的启动、测试、构建、部署、恢复命令 | 未验证命令、凭据 |
| `decisions.md` | 决策背景、选择、原因、影响 | 无依据的设想 |
| `todo-memory.md` | 待确认或待补全候选 | 可直接执行的事实约束 |

> **职责分工**：排障、Bug 修复、故障恢复与踩坑复盘等**工程经验**，由 `intelligent-experience-extractor` 独立承载，**切勿写入本目录**。

## 维护规则

默认写入前必须预览并得到用户确认。自动保存仅由本文件顶部的精确注释标记控制；标记缺失、重复或无效时视为关闭。即使开启，也必须跳过敏感、低价值或未经验证的信息。

写入前重新读取目标文件，优先更新同主题条目并保留用户编辑；写入后重新读取确认。每次只加载与当前任务相关的文件。

## 条目模板

```markdown
## [一句话标题]

- 日期：YYYY-MM-DD
- 类型：项目上下文 / 用户偏好 / 常用命令 / 架构决策 / 风险约束
- 标签：tag1, tag2, tag3
- 适用范围：整个项目 / 指定模块 / 指定环境 / 指定命令
- 置信度：已验证 / 用户确认 / 部分验证 / 待确认

### 内容
用简洁、可检索的语言记录结论。

### 适用场景
说明未来什么情况下应该读取或应用这条记忆。

### 依据
说明来自用户明确要求、代码验证、测试结果、构建结果、部署结果或文档事实。

### 注意事项
说明限制、例外、未知部分或不应过度推广的地方。

### 相关上下文
- 文件：相对路径
- 命令：必要时记录脱敏后的命令
- 参考：相关 issue、PR、文档或提交，如存在
```
